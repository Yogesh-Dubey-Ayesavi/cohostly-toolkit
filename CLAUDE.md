## Claude Code specifics

- Read `AGENTS.md` (imported above) before changing anything. This repo is **public**: every commit, branch name, issue and PR description is visible to everyone. Never paste secrets, internal URLs, or customer data, even in a draft.
- Ask before publishing to npm, creating a release or tag, changing repository settings or visibility, or force-pushing.
- Moving code in from the private repo: copy the files, keep history only if asked, strip anything private, and run the package's tests in the new location before calling it done.
- When you edit a skill, re-read its frontmatter: `name` must equal the folder name.
